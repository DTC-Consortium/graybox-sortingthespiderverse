Four Algorithms, One Race

The four algorithms selected represent a range of complexity classes from quadratic to linearithmic. This allows us to observe how algorithmic efficiency impacts performance on real-world data, even with a modest dataset of just 11 elements.

Algorithm Best Case Average Case Worst Case Space
Bubble Sort O(n) O(n²) O(n²) O(1)
Insertion Sort O(n) O(n²) O(n²) O(1)
Heap Sort O(n log n) O(n log n) O(n log n) O(1)
Quick Sort O(n log n) O(n log n) O(n²) O(log n)

These four were chosen to demonstrate the stark difference between quadratic-time algorithms (Bubble and Insertion) and linearithmic algorithms (Heap and Quick), while also showing variations in implementation complexity and practical performance characteristics.

Bubble Sort Deep Dive

Summary: Repeatedly steps through the list, compares adjacent elements and swaps them if out of order. Largest elements "bubble up" to the end each pass.

Time Complexity: O(n²) average and worst case, O(n) best case
Space Complexity: O(1) in-place

Insertion Sort Deep Dive

Summary: Builds a sorted subarray one element at a time, inserting each element into its correct position among the already-sorted prefix.

Time Complexity: O(n²) average and worst, O(n) best
Space Complexity: O(1) in-place

Heap Sort Deep Dive

Summary: First builds a max-heap from the array, then repeatedly extracts the root (maximum element) and places it at the end, shrinking the heap.

Time Complexity: O(n log n) in all cases
Space Complexity: O(1) in-place

Quick Sort Deep Dive

Summary: Selects a pivot element, partitions all other elements into those less than or equal to the pivot and those greater, then recursively sorts both partitions.

Time Complexity: O(n log n) average, O(n²) worst
Space Complexity: O(log n) stack
